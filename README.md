# PDFManager

Desktop PDF editor built with Electron, React, and TypeScript. Annotate,
highlight, erase, redact, and reorganize PDFs locally — no cloud upload, no
telemetry.

## Status

Active development. Expect rough edges. File issues at
https://github.com/Ohio15/PDFManager/issues.

## Build and run

```bash
git clone https://github.com/Ohio15/PDFManager.git
cd PDFManager
npm ci
npm run build
npm start
```

Requires Node.js 20 or later.

## Features

- Open, view, and save PDF files
- Text highlight, underline, and strikethrough
- Freehand drawing and eraser
- Page rotation and reordering
- Form-field editing
